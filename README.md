# Starnest Study — Releases

这是 **Starnest Study**（星徽自习室）的**发布仓库**。

| 项 | 说明 |
|---|---|
| 应用 | Starnest Study 1.0.0（Windows 安装版 + PWA 网页版） |
| 下载 | 从右侧 [Releases](https://github.com/Starla307/starnest-study-releases/releases) 下载 `Starnest-Study-Setup-1.0.0.exe` |

## 三个文件都要下载

| 文件 | 作用 |
|---|---|
| `Starnest-Study-Setup-1.0.0.exe` | 安装包本体（约 107 MB） |
| `latest.yml` | 更新清单：版本号、大小、校验值 —— **自动更新必需** |
| `Starnest-Study-Setup-1.0.0.exe.blockmap` | 增量更新用的分块映射 —— **自动更新必需** |

> 少传 `latest.yml` 或 `.blockmap`，应用内「检查更新」会失败。

## 主要功能（1.0.0）

- 学习计时 · 计划待办 / 日历 / 课程表
- 自习室（公开房 / 私密房：申请加入、房主解散）
- 论坛（公开发帖、评论、点赞、收藏）
- **私密论坛**：圈子 + 邀请码 + 圈内可见，不进公开推荐
- 好友 · 私信（支持图片）· 通知
- 备忘录 · 收藏图鉴 · 个人展示 · 成就
- 云端同步（Supabase 账号体系，邮箱注册 / 登录）

## 这个仓库里有什么、没有什么

这是**只放安装包的发布仓库**，用途是让桌面版能自动更新。

| | 内容 |
|---|---|
| ✅ 有 | 安装包（`.exe`）、更新清单（`latest.yml`）、增量更新映射（`.blockmap`）、本说明文档 |
| ❌ 没有 | **源代码**（源码仓库完全独立，从未推送到此仓库或任何公开地址） |
| ❌ 没有 | **任何密钥**——服务端 `service_role` 密钥只在打包机上，从不进入安装包 |
| ❌ 没有 | **任何用户数据**——数据存在独立的云端数据库里，按账号隔离 |

关于 `anon` 公钥：这是 Supabase 客户端公钥，性质等同于浏览器里的 API 地址，公开是设计使然；真正保护数据的是服务端对每张表的行级权限规则。
